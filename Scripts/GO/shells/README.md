# Retired Shell and Stager Sources

This directory contains retired historical filenames retained as inert tombstones so old links continue to resolve. The former connect-back stager, payload delivery generator, encoder helper, and interactive shell helpers have been disabled. They do not provide supported or runnable security utilities.

Do not compile, package, or restore the former payload-delivery behavior. If you need to learn detection concepts, use the defensive material in [Tradecraft/evasion.md](../../../Tradecraft/evasion.md), [Tradecraft/av-edr-evasion.md](../../../Tradecraft/av-edr-evasion.md), and [Tradecraft/network-detection.md](../../../Tradecraft/network-detection.md).

The source history may contain obsolete examples. Historical presence does not imply approval, safety, or current compatibility.
